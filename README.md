### 🎮 Featured project: [CLOUT CLASH](https://github.com/atharvkmore/clout-clash)

<a href="https://atharvkmore.github.io/clout-clash/"><img src="https://raw.githubusercontent.com/atharvkmore/clout-clash/main/docs/screenshots/fight-special.jpg" alt="CLOUT CLASH gameplay" width="100%"></a>

A Tekken-inspired browser fighting game where six parody influencers battle with superpowers drawn from their content niche: fitness, gaming, mukbang, tech, beauty and travel.

- One self-contained HTML file: plays offline, no install, no dependencies
- Vanilla JavaScript + Canvas 2D engine with combos, juggles, supers and a CPU opponent
- AI-generated character art, stages, music and announcer voice, processed by a custom Python pipeline
- Fully documented, with a project mindmap and a reproducible build

### 📊 New: [RAM Watch](https://github.com/atharvkmore/ramwatch)

A free, open-source, ultralight (~40 KB) system monitor and game overlay for Android. No ads. No subscriptions. No tracking.

- Live glass-style dashboard: RAM, CPU, GPU, battery, storage and network
- CPU-Z-style hardware info, plus a live value in the status bar next to the clock
- Slim, colour-coded game overlay (FPS, CPU, RAM, temperatures, speed) over any app
- Pauses when the screen is off; runs on Android 7 to 15
- GPL-3.0: grab a ready-made APK for convenience, or build it yourself for control
